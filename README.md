# 🚀 NISH PRO Dashboard – Interactive Frontend Dashboard System

A modern, fully functional and interactive dashboard built using pure HTML, CSS, and JavaScript.  
No frameworks. No external libraries. Just clean, structured vanilla code.

## 🎯 Key Features
### 📊 Dashboard
- Task Management (Add / Complete / Delete)
- Priority Levels (High / Medium / Low)
- Live Progress Tracking
- Real-time Statistics
- Complete All Tasks
- Clear Completed Tasks
- Export Tasks to JSON

### 📁 Projects
- Multiple Active Projects
- Visual Progress Bars
- Team Member Avatars
- Project Status Indicators
- Interactive Project Cards

### 📈 Reports
- Downloadable Reports
- File Metadata Display
- One-click Download Simulation

### 📊 Analytics
- Live Chart Visualization
- Performance Metrics
- Task Completion Tracking
- Productivity Indicators

### 👥 Team Section
- Team Member Profiles
- Online / Offline Status
- Role-based Display

### 📅 Calendar
- Interactive Calendar Grid
- Today Highlight
- Clickable Date Events

### ⚙️ Settings
- Dark / Light Theme Toggle
- Compact Mode
- Accent Color Picker
- Font Size Adjustment
- Notification Preferences
- Export / Import Data
- Reset to Default Settings

### 🎨 Extra Features
- Daily Quote Generator
- Weather Widget
- Notification System
- Smooth Animations
- Fully Responsive Design
- Modern UI Effects

## 🛠 Technologies Used

Technology | Purpose
